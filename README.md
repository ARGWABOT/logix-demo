# Logix · demo comercial

Demostración navegable de la plataforma de operación de equipos para O&M eólico.
**Frontend puro, datos ficticios.** Sin backend, sin dependencias externas.

- Tipografía Inter autoalojada (OFL) — funciona sin conexión
- Idiomas: EN (por defecto), ES, PT
- Navegación por hash, apta para GitHub Pages
- Al pulsar una acción se lanza una animación que explica qué hace el sistema

## Local

Abrir `index.html` o servir la carpeta con cualquier servidor estático.

## Publicación

GitHub Pages desde `main`, carpeta raíz.
